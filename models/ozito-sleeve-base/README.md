# Copy-sleeve base for the Ozito trim router

This folder contains a 3D printed base for the Ozito PXC 18V brushless trim router, model PXBLTS-018.
PXC is the name of Ozito's range of 18 volt battery tools.
The base replaces the router's original base plate.
The copy sleeves and nut from the MakerWorld model [Copy sleeve Parkside 10-12-14-16-18-20-24-30mm](https://makerworld.com/en/models/191715-copy-sleeve-parkside-10-12-14-16-18-20-24-30mm) fit into the base.

A copy sleeve is a short tube around the router bit.
The sleeve runs along the edge of a template, so the router cuts the same shape as the template.

## Files in this folder

| File | What it contains |
|---|---|
| `ozito-sleeve-base-test-ring.stl` | The bottom 2 mm of the base, for checking that the screw holes line up |
| `ozito-sleeve-base.stl` | The full base, ready to print |
| `ozito-sleeve-base.sc` | The editable SolidCraft design of the base |
| `copy-sleeve-13mm.stl` | A 13 mm copy sleeve, made from the original 12 mm sleeve |

## Print the base

The base has two sides.
The router side has a large round pocket for the nut.
The workpiece side is the flat side that touches the wood while you cut.

1. Print the test ring first. The test ring uses about a fifth of the plastic of the full base.
2. Put the test ring against the router, with the notch on its edge towards the dust port.
3. Start the 4 original screws by a few turns only. The test ring is thin, so the screws can reach the bottom of their holes in the router.
4. If all 4 screws start straight, print the full base.
5. Print the full base with the router side down.

## Fit the base to the router

1. Take the battery out of the router.
2. Remove the 4 screws and the original base plate.
3. Turn the base so the notch on its edge points towards the dust port. The screws also fit the other way round, but then the sleeve is about 7 mm off centre.
4. Fit the base with the router's original screws. These screws are M4 countersunk screws, 8 mm long. M4 means a metric thread 4 mm wide.

## Change a sleeve

1. Remove the base from the router.
2. Unscrew the nut on the router side of the base, and take out the sleeve.
3. Push the new sleeve in from the workpiece side.
4. Screw the nut onto the sleeve from the router side.
5. Fit the base to the router again.

## Choose a bit for the 13 mm sleeve

The hole through the 13 mm sleeve is 10.5 mm wide.
Use a router bit that is narrower than 10.5 mm.
