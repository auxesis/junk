# Ozito trim router copy-sleeve base

A sub-base for the Ozito PXC 18V brushless trim router (PXBLTS-018) that takes
the Parkside copy sleeves and nut from
[Copy sleeve Parkside 10-12-14-16-18-20-24-30mm](https://makerworld.com/en/models/191715-copy-sleeve-parkside-10-12-14-16-18-20-24-30mm)
on MakerWorld.

| File | What it is |
|---|---|
| `ozito-sleeve-base.sc` | Parametric SolidCraft design of the base |
| `ozito-sleeve-base.stl` | The base, ready to print (router face down) |
| `ozito-sleeve-base-test-ring.stl` | Bottom 2 mm of the base, for checking the screw holes |
| `copy-sleeve-13mm.stl` | A 13 mm copy sleeve, remixed from the original 12 mm sleeve |

Fit the base with the notch on its edge towards the router's dust port. It is
held on with the router's original M4 x 8 mm countersunk screws.
